# Harness Lens for Go (placeholder)

This is a buildable staging module for the future
`github.com/harness-lens/go` implementation. It deliberately exposes only
package identity and availability metadata; no analysis behavior is simulated.

Do not tag this placeholder as a public Go module. Move it to the root of the
`harness-lens/go` repository and replace the placeholder API before publishing
the first semantic version.
